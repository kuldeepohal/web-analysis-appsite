# AI Website Growth & Intelligence Platform

Analyze a website and generate a practical growth audit focused on SEO, performance, mobile readiness, accessibility, content, lead generation, security, and technical signals.

## Features

- Website Health Audit
- SEO Audit & Improvement Plan
- AI Website Content Audit
- Website Competitor Analysis
- Website Redesign Recommendations
- Local Business / Google Visibility Audit
- Lead Generation Audit
- Security & Technical Audit
- Website Technology Detection
- Website-to-Report Generator
- Website Monitoring and recurring reports

## Run locally

```bash
npm install
npm run dev
```

## Notes

- The analyzer is defensive and non-invasive.
- It currently inspects the fetched HTML and response headers for practical signals.
- More advanced features such as competitor analysis, PDF export, and recurring monitoring can be layered on top of the current audit flow.
